# Settings Form Project

## 📌 Overview
A React form with validation and testing using Vitest.

## 🚀 Features
- Form validation (name, email, password)
- Accessible inputs
- Success message handling
- Unit + integration tests

## 🧪 Testing
Run tests with:
npm test

## ⚙️ Tech Stack
- React
- Vitest
- Testing Library
